# Security and privacy

This is an unconfigured portfolio reference, not the studio's production repository. Do not test against the real business or publish customer data, credentials or private access URLs in an issue.

Please describe code concerns using synthetic reproductions and file/line references. For an actual leaked secret, avoid reposting it; use the relevant provider's reporting/revocation process and an appropriate private contact channel. Do not assume a public GitHub issue is confidential.

The code contains provider endpoints because it demonstrates integrations. Test credentials are not real credentials. This repository has no production bindings or deployment automation. Secret scanning and passing tests reduce risk but do not guarantee the absence of every vulnerability.
