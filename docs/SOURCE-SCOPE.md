# Scope of this edition

This is a fresh-history, selected-source portfolio reference. It preserves booking/calculator algorithms, selected browser controllers and markup, SQL migrations, route wrappers, private Worker source and synthetic tests. Production hostnames in selected code were replaced with `studio.example`; synthetic email fixtures use reserved example domains. The illustrative public menu snapshot is a test fixture, not a live pricing offer.

Excluded: the production `.git` directory/history, all historical docs/evidence/proof folders, handover ZIPs, database exports, customer records/images, Calendar exports, logs, real account/binding/project identifiers, telemetry identifiers, OAuth/Turnstile credentials, Google verification files, full website asset library, photos/logos, Instagram post archive and scheduled/deployment workflows.

The selected Astro/JSX files intentionally retain interfaces to the original layout/navigation components for code review. Those components and assets are not present. Therefore this edition supports `npm test` and `npm run example`, not a full Astro website build. This avoids presenting a partial or disconnected copy as a functioning live booking application.

The reference adapters can only perform real provider work if someone independently supplies valid credentials and deployment bindings. None are supplied or configured here. Local tests inject synthetic transports. The repository is not linked to production deployment.
